# TriageDesk

A Simple Reflex Agent that automatically classifies, prioritizes, and routes customer support tickets using predefined condition-action rules.

## Overview

TriageDesk is an academic project developed to demonstrate the principles of a Simple Reflex Agent through a practical helpdesk ticket management scenario.

The agent evaluates incoming tickets and selects actions based on predefined rules without relying on previous experiences or stored memory.
